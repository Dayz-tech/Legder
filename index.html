About connecting MetaTrader 5

A web page running in your browser can't reach into a desktop MT5 terminal directly — MT5 doesn't expose that connection to browsers, for the same reason no trading platform lets a random webpage read your account. There are two ways around that, both supported here:

  1. Export & import (works now): in MT5, go to the Account History tab, right-click → Report → save as a detailed statement (CSV, HTML, or PDF all work), then drop it below.
  2. Local bridge script (closest to live sync): a small Python script using MetaTrader5's official API can export your trade history straight from your terminal. Download it below, run it locally with python mt5_export.py, and import the JSON it produces. It never leaves your machine.
